# NovLearn Admin

Application privée d’administration de NovLearn. L’édition utilise Supabase
Staging ; les publications vers Production restent sélectives et protégées par
les mécanismes prévus au projet.

## Commencer

1. Lire [AGENTS.md](AGENTS.md) et le [cahier des charges](CDC_reference.md).
2. Consulter [l’index de la documentation](docs/README.md) et la
   [roadmap](docs/roadmap.md) avant de choisir un lot.
3. Suivre le [guide de développement](docs/guides/development.md) pour installer
   ou lancer l’application.

La roadmap décrit l’état observé et les travaux restants. Les guides expliquent
les pratiques courantes ; la documentation historique supprimée n’est pas
requise pour utiliser ou vérifier le code actuel.
